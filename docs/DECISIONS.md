# Decisions

Decision log for choices that are expensive to reverse: telemetry frame format, driver layout, build setup, host-side tooling. One entry per decision, appended in order, never rewritten; a changed mind gets a new entry that supersedes the old one.

No entries yet. The first one lands with the first code.

## Template

### D-NNN: Short title

- Date: YYYY-MM-DD
- Status: accepted (or: proposed, superseded by D-NNN)

**Context.** The situation that forced a choice, the constraints, the alternatives considered.

**Decision.** What was chosen and why.

**Consequences.** What gets easier, what gets harder, what to watch for.
